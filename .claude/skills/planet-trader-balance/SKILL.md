# Баланс: симулятор, опыты, отчёт

Все числа — в `src/PlanetTrader.Core/Balance.cs`; симулятор — `src/PlanetTrader.Sim` (боты, цели «Плана проверки»).
Решения автора (`CLAUDE.md`, раздел «Решения автора») не пересматривать без спроса.

```bash
export PATH=/opt/homebrew/bin:/usr/local/share/dotnet:$PATH
dotnet build src/PlanetTrader.Sim -c Release      # после правок, дальше запускать с --no-build
```

## 1. Быстрый опыт (полминуты на 10 партиях)

```bash
.claude/skills/planet-trader-balance/compare.sh <папка-для-вывода> <имя> <партий> "<стиль;стиль>" [--set Поле=значение …]
```

Печатает медианы капитала стилей на контрольных ходах и отношение к первому. Стили: «Активный», «Пассивный»,
«Активный + кредит», «Активный, только стартовый сектор», «Пассивный, только стартовый сектор»,
«Активный без разведки», «Активный, жители побоку». `--set` меняет любое поле `Balance`,
и элементы массивов тоже: `--set "Sectors[1].LicenseCost=10000"`, `--set "Magnates[0].TrickChance=0"`.

Несколько вариантов — запускать параллельно, каждый в фоне (`&`), потом `wait`. Варианты сравнивать по одной
и той же базе. 10 партий шумят на ±5–10%: вывод, на который опираемся, перепроверять на 30.

## 2. Полная проверка (≈5 минут основной прогон)

```bash
.claude/skills/planet-trader-balance/full.sh <папка-для-вывода>
```

Запускает параллельно: основной отчёт (30 партий × 1000 ходов, пишет `docs/sim/report.md` и `curves.csv`),
кооператив (3 игрока) и большой сектор (300 планет) — эти два пишут в `<папка>/coop` и `<папка>/big`,
чтобы не затереть основной отчёт. Большой сектор считается долго (больше 10 минут); если не успевает — честно
сказать автору, что он не проверен.

Начало игры точнее: `dotnet run --project src/PlanetTrader.Sim -c Release --no-build -- --runs 100 --turns 120 --out <папка>`.

## 3. Регрессия

Если правка не должна менять старое поведение (новый сектор, новый ресурс), отключить новое и сравнить
`curves.csv` побайтно с закоммиченным (`cmp`). Совпало — старое не сломано. Случайные выборы, добавленные в
новом коде, не должны тратить генератор в старом сценарии (иначе совпадения не будет).

## 4. Отчитаться

- `docs/BALANCE.md` — что меняли, цифры «было → стало», почему; открытые вопросы.
- Таблица баланса (Google Sheets `1jB2R1h7a_aBP5400BRHGXMAohjRnJE751wduXvs0e2M`): вкладки «Параметры»,
  «Разведка», «Менеджеры» и другие, где числа поменялись.
- Автору — честно, какие цели «❌» и почему; не выполненные до правки тоже назвать (сравнить с прошлым отчётом).
- Затем — навык `planet-trader-ship`.
