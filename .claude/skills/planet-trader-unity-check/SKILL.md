# Проверить в собранной игре

Глазами проверяет только автор, поэтому видимое я сначала снимаю сам. Полная справка по ключам — `docs/art/README.md`.

## Сборка (1–2 минуты)

```bash
.claude/skills/planet-trader-unity-check/build.sh      # пишет «Сборка: Succeeded …» или ошибки CS
```

- Путь к проекту в `unity run` — только полный (`/Users/davidkrasnikov/galaxy-flipper/unity`): короткое имя находит копию в Загрузках.
- `-batchmode` не передавать — `unity run` его отвергает.
- Ошибки компиляции быстрее ловит `dotnet build tools/UnityCompileCheck` — до сборки.

## Снимок

```bash
.claude/skills/planet-trader-unity-check/shot.sh <путь.png> [ключи автоснимка…]
```

Скрипт запускает игру в окне 1600×900, ждёт снимок (до минуты) и выходит. Игра делает снимок и без фокуса окна.
Частые ключи:

| Что увидеть | Ключи |
|---|---|
| Вкладку правой панели (0 Планета … 5 Развитие, 6 Магнаты) | `-autoShotTab 5` |
| Экран выбора персонажа / партию за персонажа | `-autoShotStart` / `-autoShotCharacter 2` |
| Открытый сектор (с лицензией, деньгами и уровнем «для снимка») / закрытый | `-autoShotSector 1` / `-autoShotSectorLocked 1` |
| Паузу «Ходят соперники» (портреты магнатов) | `-autoShotRivals` |
| Режим зонда, разведанную карту, жителей | `-autoShotProbe`, `-autoShotReveal`, `-autoShotPeople` |
| Клики, колесо, перетаскивание (экран 1600×900) | `-autoShotClicks "x,y;x,y"`, `-autoShotWheel "x,y,шаги"`, `-autoShotPan "x,y,dx,dy"` |
| Задержку перед снимком (планеты запекаются) | `-autoShotDelay 8` |
| Окна: шоу со вступлением, случай, «Важное за ход» | `-autoShotShow`, `-autoShotIncident tax` (id из `Balance.Incidents`), `-autoShotAlerts` |
| «Лот недели» (ходы до лота, выбрана легенда) | `-autoShotLot` |
| Сохранения: n ходов, сохранить, список; продолжить автосохранение | `-autoShotSaves 7`, `-autoShotContinue` (сохранения потом удалить: `~/Library/Application Support/DefaultCompany/unity/saves`) |

## Смотреть

Целый кадр 1600×900 мелкий — вырезать нужное и увеличить (Pillow есть в `python3`):

```bash
python3 -c "from PIL import Image; Image.open('a.png').crop((940,70,1600,710)).save('a-crop.png')"
```

Правая панель — примерно `x 940–1600`, карта — `0–940`, верхняя панель — `y 0–64`, нижние панели — `y 710–900`.
Потом открыть вырезку через Read и посмотреть глазами: обрезанный текст, наезды, переносы, пустые места.

Движение (покачивание портретов, вращение) на одном кадре не видно — снять два кадра с разной `-autoShotDelay`
и сравнить разницу (`ImageChops.difference`).

## Если снимка нет

- Лог игры: `~/Library/Logs/DefaultCompany/unity/Player.log` (ищите «Автоснимок» и `Exception`).
- Игра висит без кадров — у старых сборок окно без фокуса стоит на паузе; сейчас автоснимок включает `runInBackground`.
- Лог сборки: файл из `-logFile` в `build.sh`.

## Живой редактор автора

У автора открыт Unity с копией из Загрузок и пакетом `com.unity.pipeline`: `unity status` → `ready`. Можно спрашивать
редактор напрямую (`unity command eval '…'`), но он видит копию в Загрузках — сперва скопировать изменения
(навык `planet-trader-ship`). Сцену автора без спроса не менять.
