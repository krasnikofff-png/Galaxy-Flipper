# Графика: процедурные планеты

Планеты рисуются кодом, без готовых картинок: у каждой своя поверхность по типу и зерну, стиль единый, и их может быть сколько угодно.

| Тип в игре | Облик |
|---|---|
| Джунгли (биомасса) | тропическая зелень с рощами, моря и бирюзовые лагуны, облака |
| Ледяной карлик (лёд) | ледники с трещинами и торосами, замёрзшие моря с льдинами |
| Скалистая (металл) | ступенчатые плато, каньоны, кратеры, блестящие металлические жилы |
| Газовый гигант (газ) | полосы облаков с завихрениями и большой шторм |
| Кристальная (кристаллы) | поля кристаллов с гранями и бликами |
| Аномалия (квантий) | тёмная поверхность со светящимися разломами |

- `planets-preview.png` — превью из `tools/planet-preview/planet.py` (Python, numpy): быстро пробовать облик. Запуск: `python3 tools/planet-preview/planet.py jungle 7 600`.
- `planets-unity-check.png` — настоящий рендер Unity (6000.0.58): все восемь типов (шесть исходных, вулканическая и океан этапа 8) кодом `PlanetSnapshots` из редактора.
- `sector-map-3d.png` — собранная игра: карта сектора с 3D-планетами (все планеты открыты для снимка) и 3D-кадр выбранной планеты справа.

## В Unity

- `Assets/Scripts/Planets/` — шум (`PlanetNoise`), правила типов (`PlanetSurface`), запекание текстур (`PlanetBaker`), планета на сцене (`PlanetView`), витрина (`PlanetShowcase`), карта сектора (`SectorMapView`), крупный план в окне планеты (`PlanetPortrait`).
- `Assets/Resources/Shaders/` — поверхность, облака, ореол атмосферы, звёздное небо. Встроенный рендер Unity.
- В игре: **F2** или кнопка «Планеты (F2)» — витрина. 1–6 — тип, R — другая планета, мышь — вращать, колесо — масштаб, F2/Esc — назад.

Текстуры запекаются при открытии: 2048×1024 в витрине (около секунды), в окне планеты 1024, на карте 256. На карте и в окне планеты — в фоновом потоке: игра не замирает, планета появляется, когда готова.

## Карта сектора и окно планеты

- **Кольца:** у газовых гигантов почти всегда, у ледяных — у каждой четвёртой, у скалистых и кристальных изредка (по зерну планеты, `PlanetRings`). Полосы и просветы — текстура по радиусу, на кольцо падает тень планеты (шейдер `PlanetRing`). Кольца видны везде: на карте, в окне планеты, в витрине.
- **Биржа** — станция (`station`): центральный модуль с поясом окон, вращающееся жилое кольцо на спицах, солнечные панели, пристыкованные корабли.
- **Корабли:** зонды игрока летят по пунктиру к цели, плавно догоняя ход игры; грузовики курсируют между добывающими планетами и биржей (полоса на борту — цвет владельца), у причалов сжимаются, чтобы не было видно разворота. У обоих — голубой огонь двигателей.
- **Беды на карте:** над планетой с аварией или свежими обломками поднимается светлый дым — видно издалека.

- **Карта:** каждая планета — 3D-сфера с облаками и атмосферой, медленно вращается, у каждой свой наклон оси. Своя ортографическая камера рисует только прямоугольник карты (одна единица мира — один пиксель экрана), интерфейс поверх (UI Toolkit, Painter2D) рисует кольца владельцев, подписи и принимает клики.
- **Силуэты** серые и одинакового каменного облика: тип не выдаётся. После скана планета перезапекается в настоящий облик. Выработанные — тусклые.
- **Окно планеты:** под названием — крупный план выбранной планеты на звёздах. Камера рисует в текстуру, поэтому кадр прокручивается вместе с панелью; когда окно закрыто, камера не работает.
- В каждой партии планеты выглядят по-новому: зерно облика берётся из зерна партии.

## Постройки

Модели делает Blender из скрипта `tools/buildings/make_buildings.py`: стилизованные, но детальные (1,7–6,7 тыс. вершин: фермы из балок, перила, лестницы, трубы, техника вокруг) — их видно только в открытом окне планеты и крупно. Цвет и свойства — в вершинах, материал на все один (`Shaders/Building.shader`). Скрипт сохраняет `tools/buildings/buildings.blend`, чтобы модели можно было править руками, и выгружает FBX в `unity/Assets/Resources/Buildings`.

| Что в игре | Модель |
|---|---|
| Шахта работает | `mine_rig` — буровая вышка, огонь мигает; на газовом гиганте `mine_gas` — парящая платформа с заборником |
| Шахта стоит (авария, выработана) | та же, огни еле горят |
| Шахта строится | `mine_build` — недостроенная вышка, кран |
| Экстрактор | `extractor` — бак цвета ресурса с качалкой |
| Жители | `settlement` — купола |
| Школа | `school` |
| Охрана | `guard_tower` |
| Руины (после полной разведки) | `ruins` — колонны, арка, светящийся кристалл |

## Жители

Жители планет — десять видов инопланетян (модели `alien_*`, рост как у человечка): серые гуманоиды, осьминоги, кентавры, слизняки, ящеры, грибовики, роботы, богомолы, медузы и птицы. У каждого вида своя одежда: комбинезон, котелок и жилет, туника и попона, шарф и шапка с помпоном, комбинезон на лямках, плащ, фартук с бабочкой, цилиндр…

- Детали: тела и головы — тела вращения с талией и плечами, лица с веками, сердитыми бровями, носом и кричащим ртом с зубами и языком, кисти с пальцами, ботинки с подошвой и шнурками, пояса с пряжками, пуговицы, карманы. У каждого вида свои мелочи: присоски и монокль осьминога, грива и хвост кентавра, раздвоенный язык и гаечный ключ ящера, пластинки и румянец грибовика, заклёпки и шарниры робота, крылья богомола, жемчуга медузы, лётные очки птицы.
- На каждой планете свой вид, свой цвет кожи (в пределах, правдоподобных для вида) и «мода» — шесть цветов по зерну планеты (`Residents.Fashion`). Каждый житель одет в два своих цвета из неё: одежда и отделка (шапки, шарфы, пояса, обувь).
- В моделях кожа и одежда белые с узором: роль детали в альфе цвета вершины (0.25 — кожа, 0.75 — одежда, 0.875 — отделка), цвет даёт шейдер `Building` (`_Skin`, `_Cloth`, `_Cloth2`).
- Жители стоят на метках «…__resident» в моделях поселения (гуляют у куполов), пикета и карантина; каждый машет рукой, щупальцем, крылом или клешнёй в своём ритме (часть `gesture`), медуза парит (`hover`).
- Пожарные остались людьми: это служба вашей корпорации.
- **F4 в игре** — показать на выбранной планете другой вид жителей (по кругу; вместе с F3 видно в пикете и карантине). В окне планеты в разделе «Жители» написано, кто живёт на планете.
- `residents.png` — все десять видов в пикетах на планетах разных типов; `residents-closeup.png` — по три жителя каждого вида крупно.
- `magnates.png` — портреты магнатов в рамках их цвета (пауза «Ходят соперники»).

## Магнаты

**Картинки автора — конвейер `tools/pictures`.** Всё плоское в игре рисует автор (нейросетью по промптам из [prompts.md](prompts.md)): портреты магнатов и ведущего, карточки случаев, легендарные планеты «Лота недели», заставка и сцены итогов сезона, фон карты. Файл кладётся в `tools/pictures/source/<категория>/<имя>`, `make_pictures.py` обрезает по центру до пропорции категории, уменьшает, считает карту глубины нейросетью Depth Anything V2 Small (ONNX, локально, ~0,5 с на картинку) и кладёт в `unity/Assets/Resources/Pictures/<категория>/`. Импорт настраивает `Assets/Editor/PictureImporter.cs`: цвет — BC7/ASTC с мипмапами, глубина — без сжатия. В игре `Pictures.Load/Has` (`Scripts/UI/Pictures.cs`): без картинки — запасной вариант (бюст, значок, запечённые звёзды), так что картинка подключается просто файлом.

**2,5D.** Картинка с глубиной лежит на сетке, выдавленной по карте глубины (`MagnatePortraits`, шейдер `PortraitDepth`), и медленно покачивается: ближнее смещается сильнее дальнего, картинка «объёмная». Углы кадра срезаны, поверх — живая рамка (`PictureFrame`/`PortraitFrame` в `PlanetTraderApp.Magnates.cs`). Широкие карточки качаются вполовину слабее портретов. Фон карты и сцены — плоские (`SetBackdrop`, фон приглушается до 55%; `StyleBackground`).

Новый портрет магната: `tools/pictures/source/magnates/<имя>.png` (имя — как у модели без `magnate_`: hugo, zizi, matilda, nova, orpheus, xenon, host). У портретов с нарисованной рамкой рамку срезает `--crop l,t,r,b` (доли; у первых шести — `0.0285,0.0214,0.0285,0.0342`).

```
tools/portraits/.cache/venv/bin/python tools/portraits/make_depth.py
```

**3D-бюсты** — для магнатов без нарисованного портрета (пока это придуманные магнаты и силуэт). Их строит `tools/magnates/make_magnates.py` (Blender, как постройки: цвет и роль — в вершинах, блеск — в UV.x; акцент красится в цвет магната, «свет» светится). Голова лепится из сферы: оси растягиваются, щёки, брыли и подбородок — гауссовы бугры; нос, уши, глаза с веками, брови, губы и аксессуары — отдельные гладкие детали. Голова — подвижная часть «__head»: в игре она покачивается, грудь дышит.

```
/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/magnates/make_magnates.py
# быстрый просмотр без Unity (Eevee): портреты в папку
/Applications/Blender.app/Contents/MacOS/Blender tools/magnates/magnates.blend --background --python tools/magnates/preview.py -- /tmp/magnates
```

В Unity бюст снимает своя камера (`MagnatePortraits`) со студийным светом шейдера `PlanetTrader/Portrait`: тёплый ключевой, холодный заполняющий и контровой в цвет магната. Кадр идёт в текстуру карточки; камера работает, только пока портрет на экране. Цвета и модели магнатов — `PlanetTraderApp.Magnates.cs`; придуманные магнаты без модели — тёмный силуэт `magnate_shadow`.

**Ведущий шоу Брэд Квазар** — бюст `magnate_host` (загар, платиновый кок, улыбка во все зубы, белый смокинг с золотыми лацканами, чёрная бабочка, микрофон, звезда на лацкане), рамка золотая (`HostPortrait`). Выгрузить только его: `… make_magnates.py -- --only magnate_host`. Если автор нарисует ведущего, картинка `magnates/host` заменит бюст сама, как у магнатов.

События — тоже модели, поверх построек или рядом:

| Что в игре | Модель |
|---|---|
| Авария на шахте | `accident` поверх шахты — пожар и чёрный дым, пожарная машина с лестницей, пожарные, ограждение, мигающий маяк |
| Метеорит разбил шахту | `wreck` на её месте — упавшая вышка, смятый цех, опрокинутый бак, угли, огонь — и `crater` рядом |
| Бунт разнёс шахту | `wreck` |
| Забастовка | `picket` у шахты (без шахты — у поселения): жители поднимают плакаты в такт, транспарант, горящая бочка |
| Эпидемия | `quarantine` у поселения: палатки с крестами, лента ограждения, скорая с мигалкой |

Обломки лежат, пока не начали строить новую шахту, но не дольше 8 ходов: ядро помнит ход и причину (`Planet.MineWreckedTurn`, `MineWreckedByRiot`).

- Альфа цвета вершины — роль детали: 1 — обычная, 0.5 — акцент (в Unity красится в цвет владельца), 0 — огни (светятся и на ночной стороне). UV.x — блеск: бетон и камень матовые, металл блестит, стекло — сильнее всего.
- Места выбираются по зерну планеты и рельефу (`PlanetBuildings`): на суше, на средних широтах. Шахта с экстракторами — база, рядом поселение со школой и охраной, руины отдельно. Постройки крепятся к поверхности и вращаются с планетой.
- Окно планеты открывается всей планетой, она вращается, постройки на ней видны силуэтом. Кнопка «К постройкам» — планета замирает (облака плывут), камера подлетает к базе: постройки крупно, за ними изгиб планеты и звёзды. Поверхность там запекается в 2048.
- **Движение.** Подвижные части — дочерние объекты модели «модель__часть» с началом координат в точке вращения; как они движутся, задаёт `BuildingMotion` по имени части: балансир качалки качается, кривошип с противовесами крутится в такт, радар вращается, прожектор водит лучом, кран поворачивает стрелу с грузом, тали буровой ходят вверх-вниз, антенны поселения и газовой платформы поворачиваются. Каждая постройка — со своим сдвигом по времени, чтобы одинаковые не двигались синхронно.
- **Дым и огонь.** Источники — пустые объекты «модель__smoke_dark», «__smoke_light», «__flame» в моделях; клубы рисует и двигает шейдер `Smoke` (всё на видеокарте), время задаёт `SmokeEmitter`. Тёмный дым из трубы цеха буровой, светлый выхлоп мотора качалки, факел с огнём и копотью на газовой платформе. У шахты дым только пока она добывает. Ветер у каждой постройки свой.
- **Мышь в окне планеты.** Целиком планету можно вращать и наклонять мышью, сама она снова начинает вращаться через пару секунд. На крупном плане тянуть мышью — облететь базу (вокруг и выше-ниже). Колесо — ближе/дальше. Небо — сфера вокруг сцены, поэтому звёзды есть в любую сторону.
- **F3 в игре** — показ на выбранной планете, по кругу: все постройки → стройка шахты → авария, забастовка и эпидемия → обломки после метеорита → после бунта → выключено. Только картинка, экономика не меняется.
- `buildings-unity.png` — снимок из редактора: четыре типа планет со всеми постройками в кадре окна планеты.

```bash
# пересоздать модели и выгрузить в Unity
/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/buildings/make_buildings.py
# правили buildings.blend руками — только выгрузить
/Applications/Blender.app/Contents/MacOS/Blender tools/buildings/buildings.blend --background --python tools/buildings/make_buildings.py -- --export-only
# посмотреть каждую модель отдельно, без Unity
/Applications/Blender.app/Contents/MacOS/Blender tools/buildings/buildings.blend --background --python tools/buildings/preview.py -- /tmp/buildings
```

## Проверка без человека

```bash
# снимок всех типов настоящим рендером (из папки репозитория; путь к проекту — полный, иначе Unity CLI может найти другой проект с тем же именем)
unity run "$PWD/unity" -- -executeMethod PlanetTrader.EditorTools.PlanetSnapshots.RenderFromCommandLine -snapOut "$PWD/docs/art/planets-unity-check.png"
# снимок построек на четырёх планетах
unity run "$PWD/unity" -- -executeMethod PlanetTrader.EditorTools.PlanetSnapshots.RenderBuildingsFromCommandLine -snapOut "$PWD/docs/art/buildings-unity.png"
# видео: кадры четырёх планет со всеми постройками в движении и склейка в GIF
unity run "$PWD/unity" -- -executeMethod PlanetTrader.EditorTools.PlanetSnapshots.RenderBuildingsAnimationFromCommandLine -frameDir /tmp/frames -frames 90 -fps 15   # -events — беды вместо построек
python3 tools/buildings/frames_to_gif.py /tmp/frames /tmp/buildings.gif 1200 15
# крупный план одной модели в движении (пикет, карантин, авария…), лицом к камере
unity run "$PWD/unity" -- -executeMethod PlanetTrader.EditorTools.PlanetSnapshots.RenderCloseUpFromCommandLine -model picket -frameDir /tmp/picket
# все виды жителей в пикетах; крупно в студии — RenderResidentsFromCommandLine
unity run "$PWD/unity" -- -executeMethod PlanetTrader.EditorTools.PlanetSnapshots.RenderSpeciesFromCommandLine -snapOut "$PWD/docs/art/residents.png"
# сборка игры для macOS в unity/Build
unity run "$PWD/unity" -- -executeMethod PlanetTrader.EditorTools.BuildTools.BuildMac -buildOut Build/PlanetTrader.app
# запуск со снимком экрана через 10 секунд; -autoShotReveal разведывает все планеты сектора и выбирает вашу,
# -autoShotDrag 200 перед снимком «тянет мышью» окно планеты (облёт базы);
# -autoShotTab 3 открывает вкладку (0 — «Планета» … 6 — «Магнаты»), -autoShotProbe включает режим зонда,
# -autoShotRivals снимает паузу «ходят соперники», -autoShotClicks "1134,20;500,420" кликает мышью
```
