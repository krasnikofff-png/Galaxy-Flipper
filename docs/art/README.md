# Графика: процедурные планеты

Планеты рисуются кодом, без готовых картинок: у каждой своя поверхность по типу и зерну, стиль единый, и их может быть сколько угодно.

| Тип в игре | Облик |
|---|---|
| Джунгли (биомасса) | тропическая зелень с рощами, моря и бирюзовые лагуны, облака |
| Ледяной карлик (лёд) | ледники с трещинами и торосами, замёрзшие моря с льдинами |
| Скалистая (металл) | ступенчатые плато, каньоны, кратеры, блестящие металлические жилы |
| Газовый гигант (газ) | полосы облаков с завихрениями и большой шторм |
| Кристальная (кристаллы) | поля кристаллов с гранями и бликами |
| Аномалия (квантий) | тёмная поверхность со светящимися разломами |

- `planets-preview.png` — превью из `tools/planet-preview/planet.py` (Python, numpy): быстро пробовать облик. Запуск: `python3 tools/planet-preview/planet.py jungle 7 600`.
- `planets-unity-check.png` — те же правила из кода Unity, отрисованные формулами шейдеров: проверка переноса.

## В Unity

- `Assets/Scripts/Planets/` — шум (`PlanetNoise`), правила типов (`PlanetSurface`), запекание текстур (`PlanetBaker`), планета на сцене (`PlanetView`), витрина (`PlanetShowcase`).
- `Assets/Resources/Shaders/` — поверхность, облака, ореол атмосферы, звёздное небо. Встроенный рендер Unity.
- В игре: **F2** или кнопка «Планеты (F2)» — витрина. 1–6 — тип, R — другая планета, мышь — вращать, колесо — масштаб, F2/Esc — назад.

Текстуры запекаются при открытии: 2048×1024 в витрине (около секунды), для карты хватит 256.
