# Planet Trader (Galaxy-Flipper)

Ироничная пошаговая экономическая стратегия про галактического риелтора. План работ: [docs/ROADMAP.md](docs/ROADMAP.md).

## Структура

- `src/PlanetTrader.Core` — экономика игры на чистом C# (netstandard2.1, C# 9), без зависимостей от Unity. В Unity подключается папкой: в ней есть `PlanetTrader.Core.asmdef`.
  - `Balance.cs` — все числа из таблицы баланса. Параметры, которых в таблице нет, помечены «допущение».
  - `Game.cs` — состояние партии, действия игрока и конец хода.
  - `Exploration.cs` — знание о планетах, зонды, грузы.
  - `People.cs` — жители: налоги, просьбы, предложения.
  - `Magnates.cs` — ИИ-магнаты и их подкупы.
  - `Events.cs` — сезонные галактические события.
  - `Planet.cs`, `Market.cs`, `Order.cs`, `Rng.cs`.
- `src/PlanetTrader.Sim` — симулятор: боты трёх стилей («Пассивный», «Активный», «Активный + кредит») играют много партий и сверяются с целями из вкладки «План проверки».
- `tests/PlanetTrader.Core.Tests` — тесты правил.
- `unity/` — проект Unity с прототипом: карта сектора, окно планеты, биржа, заказы, финансы, журнал. Ядро подключено как локальный пакет (`unity/Packages/manifest.json` → `src/PlanetTrader.Core`).
- `tools/UnityCompileCheck` — проверяет, что скрипты Unity компилируются, без установленного Unity.
- `docs/BALANCE.md` — что поменялось в балансе и почему.

## Игра в Unity

1. Unity Hub → Add → Add project from disk → папка `unity/`. Подойдёт Unity 2021.3 или новее, проверял на справочных сборках 2021.3, рассчитано на Unity 6.
2. Открыть любую сцену (подойдёт пустая) и нажать Play. Сцена не нужна: `Bootstrap.cs` сам создаёт камеру и интерфейс.
3. Клик по планете — её окно справа. Пробел или Enter — конец хода, после него ~1 секунда на ход соперников (клик — пропустить). Кнопка «Зонды» включает режим зонда: выберите тип и задание, потом кликните по карте. Esc — выход из режима.

Интерфейс сделан на IMGUI (`OnGUI`) как заглушка для прототипа. Настоящий интерфейс — на этапе 7.

## Запуск ядра и симулятора

Нужен .NET 8 SDK.

```bash
dotnet test                                                    # тесты
dotnet build tools/UnityCompileCheck                           # компилируются ли скрипты Unity
dotnet run --project src/PlanetTrader.Sim -c Release           # отчёт в docs/sim/report.md, кривые в docs/sim/curves.csv
dotnet run --project src/PlanetTrader.Sim -c Release -- --brakes          # + таблица «Тормоза»
dotnet run --project src/PlanetTrader.Sim -c Release -- --set OrderChancePerTurn=0.3 --set InterestPerTurn=0.03
```

`--set` меняет любой числовой параметр из `Balance.cs` без правки кода. Ещё есть `--runs`, `--turns`, `--seed`, `--out` и `--trace "Активный"` (одна партия по ходам).

## Правила ядра

| Действие | Тратит действие | Правило |
|---|---|---|
| Купить планету | да | Без аукциона — только планету, которую нашёл ваш зонд. Остальные свободные планеты продаются с аукциона, обитаемые — самими жителями. Цена реестра считается по его оценке запаса (может ошибаться, бывают подвохи). С покупкой планета становится разведанной |
| Построить шахту | да | Строится 2 хода |
| Продать планету | да | Рыночная стоимость − 10% комиссии, планета уходит в реестр |
| Запустить зонд | да | «Москит» 150, «Стандарт» 400, «Дальнобой» 900: дороже — дальше и быстрее. Скан области открывает тип и оценку запаса и может найти скрытую планету. Полная разведка показывает точный запас, подвохи и руины |
| Нанять менеджера | да | +1 действие со следующего хода, зарплата 60/ход |
| Предложение жителям | да | Обитаемую планету продают сами жители: 80–110% цены или сделка «за школу». Чем щедрее, тем выше шанс и стартовая лояльность. После отказа 3 хода не разговаривают |
| Праздник, школа | да | Праздник +15 лояльности сразу, школа +2 каждый ход |
| Налог, зарплаты, просьбы жителей | нет | Налог даёт доход, но снижает лояльность; ниже 30 — забастовка |
| Ставка на аукционе | да | 100–130% базовой цены; магнаты тоже ставят. Проиграли — планета у магната |
| Слух о магнате, подкуп жителей магната | да | Грязные дела: портят репутацию, реестр ловит в 30% случаев (штраф 800) |
| Встречный подкуп, охрана | нет | Защита ваших жителей от подкупа магнатами |
| Продать ресурс, отправить заказ, взять или погасить кредит, страховка | нет | Заказ платит сразу, минус доставка до заказчика; отправить можно, только если груз успеет к сроку |

В конце хода по порядку: добыча и аварии, отправка груза на биржу → прибытие грузов → содержание, зарплаты, проценты, страховка, доставка → коллекторы, если денег не хватило → зонды, которые долетели → заказы → случайное открытие планеты (~1 за 7 ходов) → ход ИИ → биржа.

**События:** раз в 5–10 ходов на 4–6 ходов приходит галактическое событие: меняет цены ресурсов и планет, содержание, аварии, заказы. **Риски:** аварии, метеориты, эпидемии, бунты; страховка покрывает всё, кроме бунтов.

**Карта:** биржа в центре. Добытое с дальних планет идёт на биржу дольше и дороже. Игрок знает о планете одно из трёх: силуэт, скан или полную разведку.

**Рыночная стоимость планеты** — дисконтированный по ставке 10%/ход чистый доход от оставшейся добычи по базовым ценам, минус шахта, если её нет.

**Коллекторы:** недостача уходит в долг. Если долг выше 80% стоимости планет, коллекторы забирают самые дорогие планеты, пока долг не войдёт в лимит. Игра продолжается.
