# Planet Trader (Galaxy-Flipper)

Ироничная пошаговая экономическая стратегия про галактического риелтора. План работ: [docs/ROADMAP.md](docs/ROADMAP.md).

## Структура

- `src/PlanetTrader.Core` — экономика игры на чистом C# (netstandard2.1, C# 9), без зависимостей от Unity. В Unity подключается папкой: в ней есть `PlanetTrader.Core.asmdef`.
  - `Balance.cs` — все числа из таблицы баланса. Параметры, которых в таблице нет, помечены «допущение».
  - `Game.cs` — состояние партии, действия игрока и конец хода.
  - `Exploration.cs` — знание о планетах, зонды, грузы.
  - `People.cs` — жители: налоги, просьбы, предложения.
  - `Staff.cs` — менеджеры и их навыки.
  - `Corporation.cs` — корпорация: деньги, долг, действия, склад, исследования, поступки. Одна на каждого игрока и магната.
  - `Magnates.cs` — ИИ-магнаты, их подкупы и рейдерские иски.
  - `Events.cs` — сезонные галактические события.
  - `Development.cs` — дополнительные месторождения, технологии, специальности жителей, поступки игрока.
  - `Remarks.cs` — реплики магнатов о поступках игрока.
  - `Show.cs`, `GameShow.cs` — шоу «Риелтор года» (сезоны, задания, рейтинг, призы), случаи с выбором, «Лот недели».
  - `Alerts.cs` — важные события для окна «Важное за ход»; в `Game` их отмечает `Important(...)`.
  - `SaveGame.cs` — сохранение партии: снимок всего состояния в JSON (поля обходятся сами, общие объекты — по номеру, вещи из баланса — по имени). Загруженная партия продолжается в точности так же.
  - `Progression.cs` — уровни корпорации, стартовые персонажи, секторы.
  - `Planet.cs`, `Market.cs`, `Order.cs`, `Rng.cs`.
- `src/PlanetTrader.Sim` — симулятор: боты трёх стилей («Пассивный», «Активный», «Активный + кредит») играют много партий и сверяются с целями из вкладки «План проверки».
- `tests/PlanetTrader.Core.Tests` — тесты правил.
- `unity/` — проект Unity с прототипом: карта сектора, окно планеты, биржа, заказы, финансы, развитие (дерево технологий), магнаты, журнал. Ядро подключено как локальный пакет (`unity/Packages/manifest.json` → `src/PlanetTrader.Core`).
- `tools/buildings` — модели построек для Blender: скрипт и `buildings.blend`.
- `tools/UnityCompileCheck` — проверяет, что скрипты Unity компилируются, без установленного Unity.
- `docs/BALANCE.md` — что поменялось в балансе и почему.

## Игра в Unity

1. Unity Hub → Add → Add project from disk → папка `unity/`. Подойдёт Unity 2021.3 или новее, проверял на справочных сборках 2021.3, рассчитано на Unity 6.
2. Открыть любую сцену (подойдёт пустая) и нажать Play. Сцена не нужна: `Bootstrap.cs` сам создаёт камеру и интерфейс.
3. Логотип слева вверху — меню: «Новая игра», «Сохранить», «Загрузить». Игра сама сохраняется раз в пять ходов и при выходе; при запуске можно «Продолжить партию». Файлы — в `saves` внутри `Application.persistentDataPath` (на Mac — `~/Library/Application Support/DefaultCompany/unity/saves`).
4. Цель — шоу «Риелтор года»: сезон 40 ходов, три задания на очки, соперники — магнаты сектора, за первое место — кубок и приз. Место в рейтинге — в верхней панели, клик открывает задания и рейтинг. Раз в 2–4 хода приходит случай с выбором ответа (кнопка «Случай» вверху, если отложили). Раз в 12–18 ходов — «Лот недели»: легендарная планета на закрытых торгах против магнатов (золотое кольцо на карте, ставки — в окне планеты).
5. После хода соперников важное для вас — отняли или оспаривают планету, подкупают жителей, картель, переманили менеджера или учёных, бунт, забастовка, банкротство, новый уровень — всплывает окном «Важное за ход» с кнопкой «Показать планету». Мелочи (слухи, переманенные заказчики, метеориты) — только в журнале.
6. Клик по планете — её окно справа. Кнопка «Следующий ход», пробел или Enter — следующий ход, после него ~2,5 секунды на ход соперников (клик — пропустить). Кнопка «Зонды» включает режим зонда: выберите тип и задание, потом кликните по карте. Esc — выход из режима.

**Плейтест.** `.claude/skills/planet-trader-unity-check/playtest.sh` собирает «Planet Trader.app» (своё имя, версия с датой) и кладёт в архив вместе с памяткой [docs/playtest.md](docs/playtest.md) — `unity/Build/Playtest/PlanetTrader-mac-<дата>.zip`. Игра пишет журнал сессии (ходы, время на ход, события) в папку `playtest` рядом с сохранениями; меню → «Логи для отзыва» открывает её.

Интерфейс — на UI Toolkit: разметка `unity/Assets/Resources/UI/Game.uxml`, вид — `Game.uss` и `Theme.tss` (своя тема вместо стандартной, шрифт Inter с кириллицей). Код экрана — `PlanetTraderApp.Screen.cs`, карта — `PlanetTraderApp.Map.cs`, вкладки — `PlanetTraderApp.Tabs.cs`; панели собираются из состояния игры через `PanelBuilder` и пересобираются после каждого действия. Планеты уже настоящие: на карте и в окне планеты — вращающиеся 3D-планеты по типу, в окне планеты на них видны постройки (модели из Blender, с движущимися частями); базу можно облететь мышью, F2 — витрина крупным планом. Как это устроено и как проверить без человека — [docs/art/README.md](docs/art/README.md).

## Запуск ядра и симулятора

Нужен .NET 8 SDK.

```bash
dotnet test                                                    # тесты
dotnet build tools/UnityCompileCheck                           # компилируются ли скрипты Unity
dotnet run --project src/PlanetTrader.Sim -c Release           # 30 партий по 1000 ходов на стиль; отчёт в docs/sim/report.md, кривые в docs/sim/curves.csv
dotnet run --project src/PlanetTrader.Sim -c Release -- --brakes          # + таблица «Тормоза»
dotnet run --project src/PlanetTrader.Sim -c Release -- --set OrderChancePerTurn=0.3 --set InterestPerTurn=0.03
```

`--set` меняет любой числовой параметр из `Balance.cs` без правки кода, в том числе элементы массивов: `--set EducationCost[1]=800`. Ещё есть `--runs`, `--turns`, `--seed`, `--out`, `--threads` (сколько партий считать одновременно; по умолчанию — по числу ядер, итог от этого не зависит) и `--trace "Активный"` (одна партия по ходам).

## Правила ядра

| Действие | Тратит действие | Правило |
|---|---|---|
| Купить планету | да | Без аукциона — только планету, которую нашёл ваш зонд. Остальные свободные планеты продаются с аукциона, обитаемые — самими жителями. Цена реестра считается по его оценке запаса (может ошибаться, бывают подвохи). С покупкой планета становится разведанной |
| Построить шахту | да | Строится 2 хода |
| Продать планету | да | Рыночная стоимость − 10% комиссии, планета уходит в реестр |
| Запустить зонд | да | «Москит» 150, «Стандарт» 400, «Дальнобой» 900: дороже — дальше и быстрее. Скан области открывает тип и оценку запаса и может найти скрытую планету. Полная разведка показывает точный запас, подвохи и руины |
| Исследовать технологию | да | Одно исследование за раз, стоит денег и нескольких ходов. Открывает добычу новых ресурсов, прибавку к добыче, ускоренное восстановление или лояльность |
| Построить экстрактор | да | На дополнительном месторождении, когда изучена технология его ресурса. 40% цены шахты |
| Заселить колонистов | да | На свою необитаемую планету. У неё появляются жители: налоги, лояльность, образование |
| Учить жителей | да | Нужны школа и лояльность от 50. Три уровня, на первом выбирается специальность: технари, химики, физики, биологи, экономисты. Образованные жители зарабатывают умственным трудом (меньше, чем шахта, но всегда), а каждый уровень даёт бонус всей корпорации |
| Нанять менеджера | да | Из трёх кандидатов (меняются раз в 8 ходов): +1 действие со следующего хода, зарплата зависит от навыков. Каждое действие выполняет конкретный человек — лучший в деле или выбранный; навык (переговоры, геология, грязные дела, работа с людьми) меняет цену и результат |
| Предложение жителям | да | Обитаемую планету продают сами жители: 80–110% цены или сделка «за школу». Чем щедрее, тем выше шанс и стартовая лояльность. После отказа 3 хода не разговаривают |
| Праздник, школа | да | Праздник +15 лояльности сразу, школа +2 каждый ход |
| Налог, зарплаты, просьбы жителей | нет | Налог даёт доход, но снижает лояльность; ниже 30 — забастовка |
| Ставка на аукционе | да | 100–130% базовой цены; магнаты тоже ставят. Проиграли — планета у магната |
| Ставка на «Лот недели» | да | Закрытая: ×1–×2 от стартовой цены, поднять можно ещё одним действием. Деньги списываются только при победе; если к торгам их нет — ставка сгорает, репутация −5 |
| Ответ на случай | нет | Варианты с ценой и шансом; не ответили до конца хода — выбран последний («ничего не делать») |
| Слух о магнате, подкуп жителей магната | да | Грязные дела: портят репутацию, реестр ловит в 30% случаев (штраф 800) |
| Встречный подкуп, охрана | нет | Защита ваших жителей от подкупа магнатами |
| Продать ресурс, отправить заказ, взять или погасить кредит, страховка | нет | Заказ платит сразу, минус доставка до заказчика; отправить можно, только если груз успеет к сроку |

В конце хода по порядку: добыча и аварии, отправка груза на биржу → прибытие грузов → содержание, зарплаты, проценты, страховка, доставка → коллекторы, если денег не хватило → зонды, которые долетели → заказы → случайное открытие планеты (~1 за 7 ходов) → ход ИИ → биржа.

**События:** раз в 5–10 ходов на 4–6 ходов приходит галактическое событие: меняет цены ресурсов и планет, содержание, аварии, заказы. **Риски:** аварии, метеориты, эпидемии, бунты; страховка покрывает всё, кроме бунтов.

**Карта:** биржа в центре. Добытое с дальних планет идёт на биржу дольше и дороже. Игрок знает о планете одно из трёх: силуэт, скан или полную разведку.

**Месторождения:** истощённое месторождение восстанавливается за 6–45 ходов в зависимости от ресурса, но до 90% прежней ёмкости: каждая выработка его немного старит. На части планет есть небольшие дополнительные месторождения других ресурсов.

**Рыночная стоимость планеты** — дисконтированный по ставке 10%/ход чистый доход за цикл «добыча + восстановление» по базовым ценам, минус шахта, если её нет.

**Магнаты** запоминают, как игрок обходится с жителями, и припоминают это по своему характеру; от этого зависит, станут ли они подкупать его жителей.

**Коллекторы:** недостача уходит в долг. Если долг выше 80% стоимости планет, коллекторы забирают самые дорогие планеты, пока долг не войдёт в лимит. Если забрали последнюю, а долг остался, — банкротство, партия окончена.

**Магнаты** — такие же корпорации и живут по тем же правилам: добыча, содержание, жители, долги, банкротство. На бирже продают по текущей цене, но цену не двигают. Чем вы богаче среднего магната, тем чаще они пакостят (до трёх раз); когда вы вдвое богаче, могут устроить картель. Магнат может оспорить в реестре вашу необитаемую планету — оплатите защиту за 3 хода. Богатый магнат поглощает бедного, разорившегося сменяет новый. В большом секторе магнатов больше (один на 10 планет), но давят они на вас как трое.

**Кооператив:** `Game.New(balance, seed, players: 2)` — у каждого игрока своя корпорация, сектор общий. В симуляторе — ключ `--players`.
