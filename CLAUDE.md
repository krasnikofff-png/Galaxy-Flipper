## Как устроено

- `src/PlanetTrader.Core` — вся экономика на чистом C# (netstandard2.1, C# 9), без Unity. Все числа — в `Balance.cs`.
- `Corporation` — всё, что принадлежит участнику (деньги, долг, команда, склад, исследования, поступки). Игроков может быть несколько (кооператив), магнаты — тоже корпорации. `Game` действует от имени текущей корпорации (`SetCurrent`). Новое состояние игрока класть в `Corporation`; «своя ли планета» проверять через `IsMine`, а не через `Owner.Player`. Расстояния и размеры — только из `Balance`.
- `src/PlanetTrader.Sim` — симулятор с ботами; `tests/PlanetTrader.Core.Tests` — тесты xunit.
- `unity/` — прототип в Unity 6 (встроенный рендер, интерфейс на UI Toolkit: `unity/Assets/Resources/UI`, код — `PlanetTraderApp*.cs`). Ядро подключено как пакет. Процедурные планеты — `unity/Assets/Scripts/Planets`, шейдеры — `unity/Assets/Resources/Shaders`, модели построек и жителей — `tools/buildings/make_buildings.py` (Blender), витрина по F2. Как проверять без человека (сборка, автоснимок, автоклики) — `docs/art/README.md`.
- `tools/UnityCompileCheck` — проверка, что скрипты Unity компилируются без Unity; `tools/planet-preview/planet.py` — быстрое превью планет на Python.

## Проверки перед коммитом

```
dotnet test
dotnet build tools/UnityCompileCheck
dotnet run --project src/PlanetTrader.Sim -c Release                     # 30 партий по 1000 ходов, отчёт в docs/sim/report.md
dotnet run --project src/PlanetTrader.Sim -c Release -- --runs 100 --turns 120          # начало игры точнее
dotnet run --project src/PlanetTrader.Sim -c Release -- --runs 10 --players 3 --set SectorPlanets=90 --set MaxSectorPlanets=150   # кооператив
dotnet run --project src/PlanetTrader.Sim -c Release -- --runs 10 --set SectorPlanets=300 --set MaxSectorPlanets=500           # большой сектор
```

Изменения баланса проверять симулятором (и кооператив, и большой сектор), честно писать автору, какие цели не выполнены.

## Решения автора (не пересматривать без спроса)

- Партии длинные: 40 ходов — меньше 10% партии; симулятор считает 1000 ходов.
- Дизайн-документ — предположение, а не закон: баланс настраивать так, чтобы было интересно и развитие планет было полезным.
- Запасы планет ×3 к исходной таблице; месторождения восстанавливаются до 90% прежней ёмкости, но не ниже 30% начальной.
- Игрок должен полюбить свою планету и жителей: образование, умственный труд (меньше дохода от ресурсов), колонисты.
- Магнаты живут по правилам игрока, но на бирже продают по текущей цене и цену не двигают — её роняют только игроки.
- В будущем — сотни планет и кооператив; делать всё так, чтобы это потом не ломалось.
- Стиль графики — как у Imagine Earth: не совсем мультяшный и не совсем реалистичный. Планеты выглядят по своему типу (ледяные во льдах, джунгли зелёные и т. д.).
